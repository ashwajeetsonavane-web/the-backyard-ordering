# THE BACKYARD — Mobile Ordering Frontend v1

Mobile-first customer ordering UI for THE BACKYARD. Uses the supplied logo and menu artwork as brand reference and menu.json for exact menu/prices.

## Files
- index.html — mobile customer menu/cart/checkout UI
- menu.json — menu data
- assets/logo.jpeg — supplied THE BACKYARD logo

## Backend
The checkout currently posts to `/api/orders`. Connect this to the Supabase/Node/Vercel API after the mobile UI is confirmed.
